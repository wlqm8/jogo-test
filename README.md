# Capim & Cia

Jogo 2D de jardinagem para Windows 10/11 de 64 bits.

Use a seção Releases deste repositório para baixar o pacote do jogo.

Capim & Cia — Windows 10/11 de 64 bits

Como abrir:
1. Baixe Capim-e-Cia-Windows-x64.zip.
2. Clique com o botão direito e escolha Extrair tudo.
3. Entre na pasta Capim-e-Cia e abra Capim-e-Cia.exe.

O jogo funciona offline. Inclui 10 foices, 5 níveis de fazenda, rebirth e salvamento automático.
Em Códigos, MONEY ativa dinheiro infinito para testes e pode ser desativado.

O aplicativo foi validado no Electron/Linux; o executável não foi executado em Windows neste ambiente. Versão de testes sem assinatura digital de editor.
