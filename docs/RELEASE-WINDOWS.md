Jogo para **Windows 10/11 de 64 bits**, com janela própria e funcionamento offline.

Para jogar:

1. Baixe **Capim-e-Cia-Windows-x64.zip**, na lista de arquivos desta versão.
2. Clique com o botão direito no ZIP e escolha **Extrair tudo**.
3. Entre na pasta **Capim-e-Cia** e abra **Capim-e-Cia.exe**.

Mantenha os demais arquivos junto do executável. Não é necessário instalar Node.js nem usar a prévia da conversa.

Use **WASD ou as setas** para andar, segure **Espaço** para cortar e pressione **F11** para tela cheia.

Inclui 10 foices, 5 níveis da fazenda, rebirth e salvamento automático. Em **Códigos**, `MONEY` ativa dinheiro infinito para testes e pode ser desativado.

O aplicativo foi validado no Electron/Linux. O executável não foi executado em Windows neste ambiente. Esta é uma versão de testes sem assinatura digital de editor.

O arquivo `.sha256` permite conferir a integridade do ZIP.
